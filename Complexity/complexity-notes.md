# Time and Space Complexity

## Time Complexity
Time complexity measures how an algorithm's operations grow
as the input size increases.

### Common Complexities
- O(1) - Constant
- O(log n) - Logarithmic
- O(n) - Linear
- O(n log n) - Linearithmic
- O(n^2) - Quadratic

## Examples
- Array indexing: O(1)
- Binary Search: O(log n)
- Linear Search: O(n)
- Merge Sort: O(n log n)
- Nested loops: O(n^2)

## Space Complexity
Space complexity measures the extra memory an algorithm uses.

- Fixed variables: O(1)
- Extra array of n elements: O(n)
